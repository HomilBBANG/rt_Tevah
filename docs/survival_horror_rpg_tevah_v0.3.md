## 1. 게임 개요

### 1.1 핵심 콘셉트

신들이 사라지고 인류가 멸망한 지구. 절대신에 의해 되살아난 마지막 인간은 폐허가 된 세계에서 살아남아야 한다.

플레이어는 괴물과 감염체가 배회하는 세계를 탐험하고, 생존 자원을 확보하며, 세계를 멸망시킨 사건의 진실을 밝혀 나간다. 탐험 과정에서 다양한 초월적 존재와 조우하고, 그들의 힘을 통해 인간을 부활시켜 인류를 다시 번성시키는 것을 목표로 한다.

죽음은 현재 회차의 종료를 의미한다. 주인공은 동일한 인간으로 다시 부활하지만 진행 상황을 잃고 처음부터 생존을 시작한다. 플레이어는 이전 회차에서 익힌 괴물의 공격 패턴, 탐험 경로, 회피 타이밍을 기억한다.

**핵심 경험: 캐릭터의 성장뿐 아니라 플레이어 자신의 숙련을 통한 생존.**

### 1.2 주요 게임 경험

- 탑뷰 기반 자유 탐험
- 실시간 생존 상태 관리
- 부위별 공격이 가능한 턴제 전투
- 방향 판단과 타이밍 입력을 결합한 회피 액션
- 신체 손상 및 사지 절단
- 초월적 존재와의 거래
- 대화 선택지와 주사위(d20) 판정 **[확정]**
- 죽음과 부활을 반복하는 로그라이크 진행
- 멸망한 세계의 진실을 발견하는 미스터리
- 인간 부활과 인류 재건

### 1.3 주요 레퍼런스

**Fear & Hunger** — 어두운 분위기, 부위별 전투, 생존의 위험성, 탐험과 선택의 중요성을 참고한다. 여기에 타이밍 회피 액션을 결합해 조작 숙련도가 전투 결과에 영향을 주도록 한다.

### 1.4 화면·표현 방향 **[확정]**

- 텍스트 어드벤처로 시작한 대화 시스템을 **스토리 전개와 인물 간 대화**에 그대로 쓰고, 게임 전체는 **탑뷰 모험**으로 진행한다.
- 기준 해상도 1920×1080. 대화·전투 화면은 위아래 검은 띠(화면의 약 10.6%)를 둔다.
- 대화 화면: 상황 묘사 상자 · 시스템 메시지 · 말풍선. **주인공은 얼굴·이름표를 보이지 않는다.** NPC 는 먼저 말한 쪽이 왼쪽.

## 2. 플레이어 캐릭터

- 플레이 가능한 주인공은 **한 명**이다.
- 인류 멸망 이후 절대신 하나에 의해 무작위로 부활한 인간이다.
- 모든 회차에서 동일한 인물로 등장한다.
- 사망하면 다시 부활해 처음부터 생존을 시작한다.
- 초월적 존재들은 반복되는 죽음과 부활을 인식한다.
- 이름, 외형, 과거, 초기 능력 및 **주인공 본인의 이전 회차 기억 유지 여부**는 미정이다.

### 2.1 능력치 **[확정]**

플레이어와 모든 NPC(적 포함)는 같은 능력치를 가진다.

| 능력치 | 비고 |
|---|---|
| 근력 | |
| 지구력 | |
| 지능 | |
| 건강 | |
| 정신력 | |
| 신성력 | 스킬을 쓸 때 사용 (스킬 시스템 **[미정]**) |
| 부위별 체력 | 머리·몸통·팔·다리 (§7.2) |
| 부위별 공격력 | 값은 있으나 전투 피해 공식 **[미정]** |
| 이동 속도 | 걷기 / 달리기 (필드) |

- 대화 선택지의 주사위 판정은 이 6개 능력치를 쓴다 (§6.3).
- **영구 능력치 강화는 없다. [확정]** 회차 안에서 대화·사건으로 오르내리는 것은 가능하다.
- 능력치와 무게·생존 수치 등 다른 시스템의 관계는 **[미정]**.

### 2.2 장비창의 능력치 탭

- 왼쪽: 내 몸 상태 (부위별 체력, 절단 표시)
- 오른쪽 위: **상태이상** 목록 (이름에 마우스를 올리면 효과 설명)
- 오른쪽 아래: 6개 능력치 **육각형 그래프**

## 3. 기본 게임 진행

### 3.1 핵심 게임 루프

1. **게임 첫 시작과 처음부터 다시 할 때는 탐험 맵 한복판에서 깨어난다. [v0.2와 다름]** (v0.2 는 베이스캠프에서 시작)
2. 탑뷰 필드에서 자유롭게 이동 (걷기, Shift 달리기)
3. 장소 조사, 자원 수집, 괴물·NPC·초월적 존재와 조우 (대화·주사위 판정)
4. 적과 전투 발생 시 턴제 전투 진입 (NPC 와도 싸울 수 있다)
5. 전투에서 승리하거나 도주하여 탐험 지속
6. 베이스캠프에서 생존 상태 관리, 잠을 자서 저장
7. 문·통로 등으로 다른 지역으로 이동

탐험이 진행되면 인간 부활 및 인류 재건 콘텐츠가 추가된다. 괴물과의 전투는 항상 유리한 선택이 아니며, 도주하거나 조우 자체를 피하는 것도 중요한 생존 전략이다.

## 4. 시간 시스템

- 게임 내 하루는 **24시간**이다.
- 탐험 중에는 실시간으로 시간이 흐른다. **전투·대화·메뉴·메시지 중에는 멈춘다. [확정]**
- 베이스캠프 행동(식사·물·씻기·잠)과 조사에는 정해진 시간이 든다.
- 시간 배율: 실제 1초 = 게임 2분 (하루 약 12분) **[임시]**
- 행동별 소요 시간 **[임시]** (엑셀 값)
- NPC 는 하루 루틴(시간대)을 가질 수 있다. 예: 고양이는 06:00–12:00, 20:00–23:00 에만 베이스캠프에 온다.

## 5. 생존 시스템

| 파라미터 | 관리 요소 |
|---|---|
| 포만감 | 음식 |
| 수분 | 물 |
| 수면 | 잠 |
| 위생 | 씻기 (**물 1병 필요 [확정]**) |
| 멘탈 | 정신적 안정 |

- 각 파라미터는 0~100 (100 = 좋음), 게임 1시간마다 정해진 만큼 줄어든다. **[임시]** 시작값·감소량·경고 기준은 엑셀 값.
- 낮아지면 경고만 표시한다. **수치가 낮거나 0일 때의 효과(전투·탐험 효율, 사망 여부)는 [미정].**
- 각 파라미터가 서로 주는 영향, 회피 판정과의 연계는 추후 결정한다.

### 5.1 상태이상 (신규)

- 출혈·매스꺼움·공황 같은 상태이상을 대화·아이템·사건으로 걸고 풀 수 있다.
- 장비창 능력치 탭에 빨간 글씨로 표시하고, 마우스를 올리면 설명을 보여 준다.
- 저장에 포함되고, 새 회차에서 사라진다.
- **실제 효과·지속 시간·부활 시 처리는 [미정].** (현재 이름 3개는 테스트용)

### 5.2 소지품·무게·장비 (신규)

- **소지품 칸: 가방이 없으면 4칸. [확정]** 가방을 메면 칸이 늘어난다 (테스트용 작은 가방 +4).
- **손(왼손·오른손)에는 어떤 아이템이든 들 수 있고, 손에 든 것은 소지품 칸을 차지하지 않는다. [확정]**
- 장비 칸 **[확정]**: 가방 · 머리 · 왼손 · 몸 · 오른손 · 왼다리 · 오른다리
- 무게: 아이템마다 무게가 있다. 들고 있는 무게가 기준을 넘으면 이동이 느려지고, **최대 무게면 움직일 수 없다. [확정]**
  - 기준 무게 20, 느려짐 ×0.5, 최대 무게 30 **[임시]**. 근력과의 관계 **[미정]**.
- 손·장비에 든 아이템도 '가지고 있다' 조건과 주사위 보정에 들어간다.
- 소지품이 가득 차면 버릴 칸을 고르거나 새 아이템을 포기한다.
- 조작: 소지품 I · 장비창 Q. 두 창을 같이 열고 끌어다 놓아 장착·해제, 우클릭으로도 장착.
- 머리·몸·다리 장비 아이템과 장비 효과(방어력 등) **[미정]**.

## 6. 탐험 시스템

- 탑뷰 시점에서 캐릭터를 직접 조작한다. 걷기, **Shift 를 누르는 동안 달리기**.
- 필드에서 이동, 조사, NPC 대화, 아이템 획득이 가능하다.
- 배경은 **종말 이후의 현실 지구**이며, 건물과 시설, 자연환경 등 과거 문명의 흔적이 남아 있다.
- 장소를 조사하며 과거의 용도와 멸망의 단서를 알아낸다. 조사에는 시간이 들고, 처음 한 번만 아이템이 나온다.
- 적과 접촉하거나 대화 선택지로 전투가 시작된다.
- 적은 정해진 길을 순찰하고(걷기 속도), 시야에 들어오면 추격한다(달리기 속도). 멀어지면 포기한다.
- **적 순찰 경로는 매 회차 같다. [확정]** 외워서 피하는 것이 전략이 된다.
- 도주하면 잠시 동안 같은 적이 다시 덤비지 않는다.

### 6.1 문과 맵 이동 **[확정]**

| 방식 | 동작 |
|---|---|
| 문 | 처음엔 닫혀 있다. E 로 열고 닫는다. **닫힌 문은 지나갈 수 없고 적의 시야도 막는다.** 열린 문으로 걸어 들어가면 이동 |
| 통로 | 밟으면 바로 이동 (계단·길·동굴 입구) |
| 이용 | E 를 눌러야 이동 (사다리·엘리베이터 등) |
| 맵 가장자리 | 맵 끝으로 걸어 나가면 옆 맵으로 |
| 대화·효과 | 대화 선택지·아이템 효과로 이동 (예: NPC 가 데려다준다) |

- 맵마다 **도착 위치(P)를 여러 개** 둘 수 있고, 어느 입구로 들어오면 어느 P 에 도착할지 정한다. 정하지 않은 입구는 기본 P.
- 맵에서 바닥·벽이 아닌 곳은 검은 빈 공간이다.
- 맵에 다시 들어오면 문은 닫힌 상태로 돌아간다. **[임시]**

### 6.2 NPC 대화

- 말을 걸 때마다 대화의 시작부터 진행하고, 플래그·조건으로 내용이 갈린다.
- NPC 는 조건(플래그 등)과 하루 시간대에 따라 나타나거나 사라진다.

### 6.3 대화 선택지와 주사위 판정 **[확정]**

**주사위(d20)는 대화 선택지에서만 쓴다.** 전투 회피는 플레이어 숙련(방향+타이밍 입력)으로 판정한다.

| 선택지 종류 | 규칙 |
|---|---|
| 일반 | 그대로 진행 |
| 아이템 | 필요한 아이템이 있으면 반드시 성공 |
| 판정 | **d20 + 보정치 ≥ 목표값**이면 성공. 1 = 대실패, 20 = 대성공 (표시 확률 5~95%). 실패하면 실패 전용 분기 |
| 전투 | 그 NPC·적과 전투. 이기면 다음, 도망치면 도주 분기, 지면 사망 처리 |

- 보정치 = 능력치 + 소지·장착 아이템 보정 + 상황 보정.
- 선택지는 조건이 안 맞으면 숨기거나 회색으로 보인다. 대가는 선택지에 표시한다.

## 7. 턴제 전투 시스템

### 7.1 전투 진입 및 행동

탑뷰 탐험 도중 전투가 발생하면 별도의 턴제 전투 화면으로 전환된다. 플레이어는 자신의 턴에 행동을 선택하고, 적의 공격 턴에는 회피 액션을 수행한다.

**행동 [v0.2와 다름]: 공격 / 특수 / 아이템 / 도주**

| 행동 | 내용 |
|---|---|
| 공격 | 적 부위를 골라 공격 (부위별 체력·명중률 표시) |
| 특수 | 스킬 사용·무기 던지기 등 특수 행동. **내용 [미정]** (스킬은 신성력 사용) |
| 아이템 | 소지품을 열어 소모품 사용. 아이템 사용이 턴을 쓰는지 **[임시: 씀]**. 전투 중 장비 교체 **[미정]** |
| 도주 | 주사위(1~100)가 **적마다 다른 도주 성공률** 이하면 성공. 다리가 잘리면 도주 불가 **[임시]** |

- v0.2 의 '방어'는 화면에서 뺐다 (규칙은 남아 있어 다시 넣을 수 있음).
- 턴 순서: 플레이어 → 적 **[임시]**.
- **NPC 와도 싸울 수 있다. [확정]** 적과 NPC 를 구분하지 않는다.

### 7.2 부위별 공격

플레이어와 적 모두 상대의 신체 부위를 선택해 공격할 수 있다. 부위별로 명중 난도와 손상 효과가 다르며, 파괴된 부위를 사용하는 행동은 제한되거나 불가능해진다.

| 부위 | 전술적 역할 예시 |
|---|---|
| 머리 | 치명적 공격을 노리는 고위험 부위 |
| 몸통 | 안정적으로 피해를 주는 주요 부위 |
| 왼팔 | 해당 팔을 사용하는 공격 무력화 |
| 오른팔 | 해당 팔을 사용하는 공격 무력화 |
| 왼다리 | 이동 및 관련 행동 제한 |
| 오른다리 | 이동 및 관련 행동 제한 |

- 머리·몸통이 파괴되면 사망, 팔다리는 절단된다.
- 부위 파괴 후에도 괴물은 남은 신체로 다른 공격을 할 수 있다 (그 부위를 쓰는 공격은 못 씀). 괴물마다 부위 구성이 다를 수 있다.
- 부위별 체력·명중률은 데이터 값. **피해량 공식 [미정]** (지금은 플레이어 피해 10 고정, 적은 공격마다 정한 피해 **[임시]**).

### 7.3 전투 화면 **[확정]**

- 왼쪽 위: 적 이름 / 가운데: 적 그림 / 왼쪽 아래: 내 상태 (부위별 체력)
- 가운데 아래: 텍스트 창 (시스템 메시지, 공격할 부위 같은 세부 선택지) — 배경 불투명도 70%
- 텍스트 창 오른쪽: 행동 버튼
- "적이 나타났다" 문구는 처음에만 보인다.

## 8. 혼합형 회피 액션 시스템

### 8.1 기본 규칙

적의 공격 턴에는 **공격 부위 판단 + 정확한 타이밍 입력**을 동시에 요구한다.

| 적이 공격하는 부위 | 키보드 입력 |
|---|---|
| 머리 | **W** |
| 왼팔 또는 왼다리 | **A** |
| 몸통 | **S** |
| 오른팔 또는 오른다리 | **D** |

방향키·게임패드 십자키도 쓸 수 있다.

### 8.2 판정 흐름

1. 적의 공격 모션 시작
2. 공격 대상 부위의 전조 확인 (내 상태 그림에 그 부위가 강조되고, 줄어드는 원이 고리에 닿는 순간이 타이밍)
3. 플레이어가 공격 부위 판단
4. 해당 키를 적절한 타이밍에 입력
5. 방향과 타이밍 정확도 판정
6. 회피 또는 피격 결과 적용

### 8.3 회피 판정

| 판정 | 조건 | 결과 |
|---|---|---|
| 완벽 회피 | 정확한 방향, ±0.08초 **[임시]** | 피해 없음 |
| 일반 회피 | 정확한 방향, ±0.2초 **[임시]** | 피해 없음 (추가 자원 소모 **[미정]**, 스태미나 없음) |
| 실패 | 잘못된 방향 또는 타이밍 | 공격 적중 |

### 8.4 공격 패턴 **[확정 — 4종 구현]**

- 일반 공격: 명확한 전조
- 속공: 짧은 예고 시간
- 연속 공격: 한 턴에 여러 부위를 차례로 공격
- 기만 공격: 공격 전조가 도중에 다른 부위로 바뀜

패턴 유형별 적용 범위와 난이도는 괴물 데이터로 정한다.

## 9. 신체 손상 및 사지 절단

- 특정 부위에 공격을 받으면 부상이 발생한다. 부상·절단은 한 회차 동안 전투 사이에 이어진다.
- 팔 또는 다리가 절단되면 해당 회차에서 기능을 상실한다.
  - 양팔 절단 → 공격 불가, 다리 하나라도 절단 → 도주 불가 **[임시]**
  - 이미 잘린 부위를 노린 공격은 몸통으로 들어간다 **[임시]**
- **사지 절단은 일반적인 치료로 복구할 수 없다.**
- 절단 이후 선택지는 **초월적 존재와 거래해 복구**하거나 **현재 회차를 끝내고 처음부터 재시작**하는 것이다.
- 절단에 따른 탐험 중 제약 **[미정]**.

## 10. 초월적 존재와의 거래

현재 확정된 거래 용도는 **사지 복구**다.

1. 초월적 존재가 거래 조건을 제시한다.
2. 거래 성립 시 플레이어가 대가를 **즉시 지불**한다.
3. 거래 완료 시 절단된 신체가 복구된다.
4. 거래 대가나 미이행 채무를 다음 회차로 이월하지 않는다.

- 구현 방식: 초월적 존재와의 대화 선택지로 만든다. "그 팔다리가 잘렸다" 조건으로 선택지를 보이고, 같은 선택지에서 대가 지불(아이템 소모 등)과 복구가 함께 일어난다.
- 존재별 거래 조건과 대가의 종류는 **[미정]**.

## 11. 로그라이크 및 부활 시스템

### 11.1 사망과 재시작

- 사망하면 먼저 **부활 수단**을 확인한다.
  - **초월적 존재의 보호나 부활 아이템이 있으면: 소지품·시간·생존 상태·부상·플래그를 모두 유지한 채 베이스캠프에서 깨어난다. [확정]** (부활 아이템은 소모)
  - 부활할 때 치명 부위(머리·몸통)만 회복하고 잘린 팔다리는 그대로 **[임시]**.
  - **부활 수단이 없으면 현재 회차가 종료되고 처음부터 다시 시작한다.** 탐험 맵 한복판에서 깨어난다.
- 주인공은 매번 **동일 인물**이다.
- 초월적 존재들은 이전 죽음과 부활을 인식한다. 대화에서 **죽은 횟수·회차 수**를 조건으로 쓸 수 있다 (예: "또 왔네" 대사).

### 11.2 회차별 처리 (부활 수단 없이 사망)

| 항목 | 사망 후 처리 |
|---|---|
| 주인공의 정체 | 동일 인물 |
| 체력 및 생존 상태 | 초기화 |
| 부상 및 사지 절단 | 초기화 |
| 장비 및 소지품 | 초기화 |
| 상태이상 | 초기화 |
| 탐험 및 스토리 진행도 | 초기화 |
| 플레이어가 배운 패턴과 지식 | 플레이어 경험으로 유지 |
| 초월적 존재의 반복 부활 인식 | 유지 (회차 수·사망 횟수 기록) |
| 능력치 | 초기값으로 (영구 강화 없음 **[확정]**) |

플레이어는 반복 플레이를 통해 괴물의 공격 전조, 회피 타이밍, 위험 지역, 안전한 경로와 적을 따돌리는 방법을 익힌다.

- 사망·부활 연출 **[미정]** (지금은 '사망' 창 하나).

## 12. 베이스캠프

- **안전한 베이스캠프는 한 곳**이다.
- 생존 상태 관리, 탐험 준비, 생활 행동, NPC·초월적 존재와의 상호작용에 사용한다.
- 거점 메뉴: 식사, 물 마시기, 씻기(물 1병), 잠.
- **잠**: 1시간 단위로 시간을 골라 잔다 (← → 로 조절). 자고 나면 저장한다.
- **고양이(하나)** 가 와 있는 시간대에는 고양이에게도 저장할 수 있다.
- 일부 초월적 존재가 방문할 수 있다.

## 13. 저장 시스템

### 13.1 확정 규칙

- **베이스캠프에서만 게임을 저장할 수 있다.** 방법은 잠, 또는 고양이.
- 탐험 중 일반 저장은 불가능하다.
- **저장 슬롯 5개**, 저장할 때마다 슬롯을 고른다 (이미 쓴 슬롯은 한 번 더 눌러 덮어씀, 저장하지 않기도 가능).
- 저장 시 현재 회차의 생존 상태, 소지품·장비, 상태이상, 진행도, 신체 손상 상태 등을 기록한다.
- **사망해도 저장 슬롯을 지우지 않는다. [v0.2와 다름]** 타이틀의 '이어하기'로 죽기 전 저장을 불러올 수 있다. 새 회차에서 저장하면 덮어쓴다. (v0.2: '이전 저장을 불러와 죽음을 취소할 수 없다')
- 회차 수·사망 횟수·월드 플래그는 회차와 별도로 계속 남는다.

### 13.2 미확정 규칙

탐험 중 게임을 종료할 때:

- 마지막 베이스캠프 저장 지점으로 돌아가는 방식 **[임시: 현재 동작]**
- 일회성 임시 저장 후 종료 위치에서 이어하는 방식

중 하나를 추후 결정한다.

## 14. 세계관 및 주요 서사

### 14.1 절대신

원래 지구에는 신들이 존재했다. 절대신은 **알파와 오메가**로 나뉘어 있었으며, 세계를 유지해야 하는 자신의 의무에서 벗어나기를 원했다.

### 14.2 니키타의 신 살해

알파인 **윈터**는 인간 **니키타**에게 하위 신들을 죽이라고 명령하고, 대가로 니키타가 원하는 유토피아를 약속했다. 니키타는 오메가의 피를 이용해 죽음 이후 과거로 회귀하며 신들을 살해했다. 그러나 약속된 유토피아는 존재하지 않았다. 절대신의 목적은 오직 자신의 의무에서 벗어나는 것이었다.

### 14.3 절대신의 재결합

오메가는 니키타를 사랑하게 되었다. 마지막 순간 알파와 오메가는 하나로 합쳐졌고, 오메가는 니키타를 집어삼켰다. 그러나 절대신은 **세계 그 자체**였기에 세계를 떠날 수 없었다. 니키타는 신에게 먹힌 이후에도 반신급 존재로 남아 있다.

### 14.4 인류 멸망

절대신은 인간을 멸망시키기 위해 괴물 또는 감염성 재앙을 만들어냈다. 인간은 감염과 괴물의 공격으로 멸망했고, 지구에는 폐허와 과거 문명의 흔적이 남았다.

### 14.5 주인공의 부활

**하나**는 니키타가 원했던 유토피아를 실현하기 위해 무작위로 인간 한 명을 부활시켰다. 그 인간이 주인공이다. 하나는 주인공이 인류를 복원할 가능성을 관찰한다.

## 15. 주요 초월적 존재

| 이름 | 분류 | 주요 설정 |
|---|---|---|
| 윈터 | 절대신 | 알파 |
| 하나 / 하누쉬 | 절대신 | 오메가, 주인공을 부활시킨 존재 |
| 에밀 | 절대신의 잔여물 | 태반과 유사한 존재 |
| 요슈아 | 외계인 | 달에서 태어난 존재 |
| 케샤 | 외계 혼혈 | 요슈아와 인간 사이에서 태어난 존재 |
| 니키타 | 반신급 인간 | 신 살해자, 신에게 먹힌 인간 |

이들은 모두 동일한 종류의 수호신이 아니며 기원과 본질이 다르다. 하나 외의 존재들은 특정 조건을 만족했을 때 등장한다. 세부 조건은 미정이다.

### 15.1 하나 / 하누쉬

- 동일한 기억·의식·성격을 가진 한 존재다.
- 낮의 인간 모습은 여성 **하나**, 밤의 인간 모습은 남성 **하누쉬**다.
- 고양이와 인간의 모습 사이를 자유롭게 변할 수 있다.
- **고양이 모습에서는 인간의 언어로 말할 수 없다.**
- 무뚝뚝하고 호전적이며 인간에게 기본적으로 호의적이지 않다.
- 니키타를 깊이 사랑한다.
- 고양이 모습으로 주인공 주변을 맴돌거나 베이스캠프를 방문할 수 있다. **고양이는 정해진 시간대에 베이스캠프에 오며, 와 있을 때 저장할 수 있다. [확정]**
- 초월체 부활: 하나의 보호를 받고 있으면 사망 시 베이스캠프에서 깨어난다 (§11.1).
- 가끔 주인공을 돕지만, 동기는 주인공에 대한 애정보다 니키타의 유토피아 실현에 있다.

## 16. 인간 부활 및 인류 재건

주인공은 인류가 멸망한 세계에서 홀로 생존을 시작한다. 탐험과 초월적 존재와의 상호작용을 통해 다른 인간을 부활시킬 방법을 발견할 수 있다. 반신급 존재나 외계인의 힘이 관여할 수 있으나 구체적인 방식은 미정이다.

부활한 인간은 고유한 성격과 특성을 가진 NPC로 등장한다. 작업 배정, 인간관계, 멘탈 영향 등 생활 시스템의 세부 범위는 추후 결정한다.

## 17. 1인 개발 범위 및 구현 우선순위

### 17.1 핵심 범위

| 부위 손상 및 사지 절단 | 동작 |

### 17.2 권장 개발 순서

1. **전투 프로토타입:** 부위 선택, 공격 전조, 방향·타이밍 회피, 부위 파괴 — 완료
2. **탐험 프로토타입:** 탑뷰 이동, 적 조우, 전투 진입, 도주 및 필드 복귀 — 완료
3. **생존 및 베이스캠프:** 시간 진행, 생존 파라미터, 생활 행동, 저장 — 완료
4. **로그라이크:** 사망, 회차 초기화, 부활, 회차 인식 — 대부분 완료 (연출 남음)
5. **콘텐츠 확장:** 지역, 괴물, 초월적 존재, 거래, 인간 부활, 서사 — 다음 단계

모든 화면은 아직 아트 없이 도형·글자로 대신한다. 데이터는 테스트용 더미다.

## 18. 미확정 사항

**기획 결정 필요**

1. 주인공의 신상, 성격, 과거 및 초기 능력치

## 19. 데이터·제작 도구 (참고)

콘텐츠는 코드를 고치지 않고 아래 파일만 고쳐서 만든다. 고친 뒤 '변환·검사'를 하면 오류를 알려 준다.

| 원본 | 담는 것 | 편집 |
|---|---|---|
| `tools/sheets/player.xlsx` | 주인공(능력치·이동 속도), 플레이어 부위, 장비 칸 | 엑셀 |
| `tools/sheets/npc.xlsx` | 모든 NPC·적 (능력치·이동 속도·도주 성공률·그림), 부위, 공격 | 엑셀 |
| `tools/sheets/item.xlsx` | 아이템 (무게·장착 칸·가방 칸·판정 보정), 조사 Loot | 엑셀 |
| `tools/sheets/content.xlsx` | 능력치 이름, 상태이상, 생존 수치, 거점 행동, 부활 규칙, 설정값, 1단계 테스트 에피소드 | 엑셀 |
| `tools/dialogues/*.json` | 대화 (대사·선택지·기능 카드) | Godot '대화' 탭 |
| `tools/maps/*.json` | 맵 모양, 물체(적·조사·NPC·거점·문·통로·이용·도착 P), 가장자리 이동 | Godot '맵' 탭 |

- **대화 탭**: 대사 카드를 선으로 잇는다. 효과 카드(아이템·플래그·생존 수치·상태이상·팔다리 복구·저장·맵 이동)와 조건 분기 카드, 조건·효과는 목록에서 고른다. 미리보기로 바로 실행.
- **맵 탭**: 벽·바닥 칠하기, 물체 놓기, 가장자리 설정, 도착 P 와 이어지는 곳 고르기, 테스트 플레이.
- 두 탭 모두 위쪽 '❓ 사용법'에 쓰는 법이 있다.

## 20. 변경 이력

- 방향: 텍스트 어드벤처 → 탑뷰 모험. 대화 시스템은 스토리·인물 대화에 사용.

- 맵 이동 5가지(문·통로·이용·가장자리·대화 효과), 도착 P 여러 개.
- 문 열고 닫기, 닫힌 문은 시야 차단. 달리기(Shift).
- 사지 복구 거래의 구현 방식(대화 선택지 + 즉시 대가) 정리.
